# Starmux

Starmux is a Rust CLI for a vertical tmux sidebar. It requires a tmux build with [side-status support](https://github.com/tmux/tmux/pull/5468).

## Structure

- `src/main.rs`: CLI and generated tmux adapter
- `src/tmux.rs`: tmux queries, snapshots, focus validation, and activation
- `src/sidebar.rs`: configuration, safe formatting, and rendering
- `src/navigation.rs`: cross-session click targets
- `tests/tmux.rs`: live attached-client contracts

See [docs/configuration.md](docs/configuration.md) for configuration and [docs/releasing.md](docs/releasing.md) for releases.

## Checks

```sh
cargo fmt --check
cargo clippy --locked --all-targets -- -D warnings
cargo test --locked
```

Live sidebar tests skip when tmux lacks side-status. On a supported build, require them with:
```sh
STARMUX_REQUIRE_SIDE_STATUS=1 cargo test --locked --test tmux
```
`make` installs the binary. If the generated adapter changes, also regenerate and source `starmux init tmux` before testing the live setup.

## Constraints

- Treat names and tmux option values as untrusted data. They must not become tmux formats, styles, or click ranges.
- Keep the snapshot producer and parser in lockstep, including their version and validation.
- Test through the `Sidebar`, `Application<T: Tmux>`, or CLI interface. Use `tests/tmux.rs` when behavior depends on tmux itself.
- Keep `main.rs` thin and preserve the existing module seams.
- Update `CHANGELOG.md` for user-facing changes.
- `.github/workflows/release.yml` is generated by cargo-dist.
